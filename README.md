# Академия зарубежного YouTube — лендинг

Страница воронки мини-курса, версия без геймификации (основная). Обычный статический сайт: HTML, CSS и JavaScript, ничего собирать не нужно.

## Версии (ветки)

| Ветка | Для чего |
|---|---|
| `main` | обычный статический сайт для любого хостинга: GitHub Pages, Netlify, свой сервер |
| [`vercel`](https://github.com/MikeEgorshev/yt-academy-landing/tree/vercel) | для Vercel: настройки `vercel.json` и обработчик заявок `api/lead` (заявки уходят в Telegram и/или Google Таблицу) |
| [`tilda`](https://github.com/MikeEgorshev/yt-academy-landing/tree/tilda) | для Тильды: код для блока «HTML-код» (T123) и для HEAD страницы в папке `tilda/` |

| Файл | Что это |
|---|---|
| `index.html` | сама страница |
| `privacy.html` | политика конфиденциальности (черновик: впишите реквизиты) |
| `assets/css`, `assets/js`, `assets/img` | стили, скрипты, картинки |
| `assets/js/config.js` | все настройки страницы |
| `integrations/google-apps-script.gs` | приём заявок в Google Таблицу с уведомлением в Telegram |
| `dist/landing-single-file.html` | та же страница одним файлом: стили, скрипты, библиотеки и шрифты встроены, открывается двойным кликом и без интернета |
| `tilda/head.html`, `tilda/block.html` | **ветка tilda:** код для HEAD страницы и для блока «HTML-код» (T123) |
| `tilda/privacy-block.html` | **ветка tilda:** политика конфиденциальности для отдельной страницы `/privacy` |
| `tilda/yta-tilda.css`, `tools/build-tilda.mjs` | **ветка tilda:** стили для Тильды и скрипт, который собирает папку `tilda/` |

## Тильда (эта ветка)

Готовый код — в папке `tilda/`. Стили, скрипты и картинки страница берёт с jsDelivr прямо из этого репозитория (тег `tilda-v1`), поэтому репозиторий должен оставаться публичным.

1. Создайте в Тильде пустую страницу, без шапки и подвала Тильды: у лендинга свои.
2. **Настройки страницы → Дополнительно → «HTML-код для вставки внутрь HEAD»** — вставьте содержимое `tilda/head.html`.
3. Добавьте блок **Другое → T123 «HTML-код»** и вставьте в него `tilda/block.html`. В начале кода блока — настройки страницы (`window.SITE_CONFIG`): видео, куда уходят заявки, бот, счётчик мест. Их можно менять прямо там.
4. Опубликуйте страницу и проверяйте опубликованную версию: в редакторе Тильды код блока не выполняется.
5. Политика конфиденциальности: отдельная страница с адресом `privacy` (Настройки страницы → Адрес страницы), на ней блок T123 с `tilda/privacy-block.html`. Ссылки лендинга ведут на `/privacy`.

Заявки. Форма своя, в «Заявки» Тильды она не попадает. В `leadEndpoint` укажите URL Google Apps Script (`integrations/google-apps-script.gs`, заканчивается на `/exec`) или обработчик из ветки `vercel` — `https://<проект>.vercel.app/api/lead`. Пусто — демо-режим.

Почему стили переписаны: в CSS Тильды есть общие правила вроде `#allrecords a { color: #ff8562 }`, они перекрасили бы кнопки страницы. Поэтому в `yta-tilda.css` у каждого правила приставка `#yta#yta` (страница лежит в `<div id="yta">`): так оно сильнее правил Тильды и не задевает другие страницы сайта.

После правок:
- текст и картинки — меняйте прямо в коде блока в Тильде или правьте `index.html` и пересоберите: `node tools/build-tilda.mjs`;
- стили и скрипты — закоммитьте правки, поставьте новый тег (`git tag tilda-v2 && git push --tags`), пересоберите `node tools/build-tilda.mjs --tag tilda-v2` и вставьте новые `head.html` и `block.html`.

Если блока T123 нет в библиотеке на вашем тарифе Тильды — проверьте условия тарифа.

## Настройки — `assets/js/config.js`

- `youtubeId` — ролик на первом экране (ID из ссылки `youtube.com/watch?v=…`).
- `leadEndpoint` — куда уходят заявки из формы «Забронировать место». Пусто — демо-режим, заявка только печатается в консоль браузера. Как подключить Google Таблицу — в начале `integrations/google-apps-script.gs`.
- `telegramBot` — бот, куда человек переходит после заявки.
- `spotsTotal`, `spotsLeft`, `spotsEveryMs`, `spotsJitter`, `spotsMin` — счётчик мест.
- `metrikaId` — Яндекс Метрика.

## Как открыть и выложить

- Посмотреть: открыть `index.html` в браузере (или `dist/landing-single-file.html`).
- Выложить: загрузить папку целиком на любой статический хостинг — GitHub Pages, Cloudflare Pages, Netlify. Сборка не нужна.

Рабочий сайт с уроками, входом через Google и профилем ученика: https://yt-academy.pages.dev
